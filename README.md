## Cliente chat con LLM

Interfaz web desarrollada con React para conversar con un modelo de lenguaje (LLM). Incluye scroll automático, exportación de mensajes y persistencia en localStorage.

## 🛠️ Tecnologías
- ⚛️ React + Vite
- 🎨 Tailwind CSS
- 📦 React Hook Form
- 📚 React Markdown

## ✨ Funcionalidades
- Envío de preguntas y recepción de respuestas vía API.
- Visualización de mensajes con estilos tipo chat.
- Scroll automático al último mensaje.
- Persistencia de la conversación en localStorage.
- Botón para limpiar historial.
- Exportación de la conversación en `.txt`.

## ▶️ Ejecutar localmente

1. Clona el repositorio:

```bash
git clone https://github.com/YonierGM/langChain-ollama.git
cd langChain-ollama

```

2. Instalar paquetes:

```bash
npm install
```

3. Correr app:

```bash
npm run dev
```
